# PAP 移动端适配测试用例

**版本**: v1.0  
**创建日期**: 2026-06-09  
**测试环境**: iOS Safari / Android Chrome，主测机型 375px 宽（iPhone 14）、390px（iPhone 15 Pro）、360px（Android 中档机）  
**测试页面**: D-PAP-MANAGER.html · D-PAP-AI-CENTER.html · D-PAP-WORKER.html · D-PAP-FINANCE-TASKS.html · D-PAP-AI-message.html

## 通用规范（所有页面共用）

在所有角色视图执行下列基础检查，不在各角色章节重复列出。

| ID | 检查项 | 操作步骤 | 预期结果 |
|---|---|---|---|
| G-01 | 视口 meta 设置 | 用 DevTools 模拟 375px，查看页面宽度 | 无横向滚动条，内容不超出屏幕宽度 |
| G-02 | 字体可读性 | 检查正文字号 | 最小字号 ≥ 14px，不需要缩放即可阅读 |
| G-03 | 点击目标尺寸 | 测量所有按钮、链接可点击区域 | 触控区域高度 ≥ 44px，宽度 ≥ 44px |
| G-04 | 长文本截断 | 切换至 360px 视口 | 长标题/描述不溢出容器，以省略号截断或自动换行 |
| G-05 | 图片自适应 | 页面含图片/图标时检查缩放 | 图片宽度不超出父容器，不变形 |
| G-06 | 横屏适配 | 将设备旋转至横屏（568px × 320px）| 布局不破损，内容仍可正常操作 |
| G-07 | 键盘弹起不遮挡输入框 | 点击 Chat / 搜索输入框 | 虚拟键盘弹起后，输入框仍在可视区域内 |
| G-08 | 键盘收起恢复布局 | 点击输入框后点击空白区域 | 虚拟键盘收起，页面布局恢复正常 |
| G-09 | 滚动流畅性 | 在长列表上快速滑动 | 滚动平滑，无明显卡顿或空白闪烁 |
| G-10 | 弹窗/抽屉边距 | 触发任意弹窗/抽屉 | 弹窗内容距屏幕边缘 ≥ 16px，关闭按钮可轻松点击 |
| G-11 | Toast 不遮挡操作区 | 触发 Toast 提示 | Toast 出现在顶部或底部安全区，不遮挡主要操作按钮 |
| G-12 | 底部安全区 | 在 iPhone（含 Home Bar）上查看底部固定元素 | 底部导航/按钮不被 Home Bar 遮挡（env(safe-area-inset-bottom) 已处理） |
