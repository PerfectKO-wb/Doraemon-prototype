## 1.创建JE tool：nn

入参：


| 序号  | 字段名称                 | 字段类型    | 是否必填 | 字段说明                                                                                                                                            |
| --- | -------------------- | ------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Accounting Date 会计日期 | Date 日期 | ✅ 必填 | 分录所属会计期间，格式：YYYY-MM-DD                                                                                                                          |
| 2   | Company Code         | 枚举文本    | ✅ 必填 | 公司主体代码，固定枚举值：SH_WYYCX_INC / SH_CYZD_INC / JP_CTW_INC / SG_CTW_INC / US_CTW_INC / HK_CTW_INC / KY_CTW_INC / TW_CTW_INC；系统自动映射对应地区（Region），无需单独填写 |
| 3   | Description 描述       | Text 文本 | ✅ 必填 | 平账原因、业务描述、单据备注，用于对账追溯                                                                                                                           |
| 4   | 分录 lines             | List 列表 | ✅ 必填 | 支持多条借贷分录（1借多贷 / 多借1贷），借贷合计须相等。每条分录包含：科目代码（Account Code）或科目名称（Report Name）**二选一**即可（两者存在强制1对1绑定，系统自动补全另一个）、借方金额（debit）、贷方金额（credit）              |


> 分录约束：至少包含一条借方分录和一条贷方分录；所有分录借方金额之和 = 所有分录贷方金额之和。

## 4.通过上传csv/excel批量创建JE

文件格式如下，均为必填字段  
**字段说明：**


| **列名**            | **类型**     | **必填** | **说明**                         |
| ----------------- | ---------- | ------ | ------------------------------ |
| `je_no`           | 整数         | ✅      | 用户自定义分组编号，相同编号的行归为同一条 JE       |
| `accounting_date` | YYYY-MM-DD | ✅      | 每行都需填写（同组内保持一致）                |
| `company_code`    | 枚举         | ✅      | 每行都需填写（同组内保持一致）                |
| `description`     | 文本         | ✅      | 每行都需填写（同组内保持一致）                |
| `account_code`    | 文本         | 二选一    | 科目代码，与 `report_name` 提供其中一个即可  |
| `report_name`     | 文本         | 二选一    | 科目名称，与 `account_code` 提供其中一个即可 |
| `debit`           | 数字         | 借贷各填一个 | 借方金额，贷方行留空                     |
| `credit`          | 数字         | 借贷各填一个 | 贷方金额，借方行留空                     |


**校验规则（与单条创建一致）：**

- 同一 `je_no` 组内，至少含一行借方、一行贷方
- 同一 `je_no` 组内，`sum(debit)` = `sum(credit)`
- `account_code` 与 `report_name` 同行内至少填一个，可都填、不可都空。都填时需要校验`account_code` 与 `report_name` 是否匹配
- `debit` 与 `credit` 同行内只能填一个（另一个填0或者为空）  
  
示例：

  | **je_no** | **accounting_date** | **company_code** | **description** | **account_code** | **report_name** | **debit** | **credit** |
  | --------- | ------------------- | ---------------- | --------------- | ---------------- | --------------- | --------- | ---------- |
  | 1         | 2026-04-30          | JP_CTW_INC       | 四月服务费核销         | 1002             |                 | 50,000    |            |
  | 1         | 2026-04-30          | JP_CTW_INC       | 四月服务费核销         | 2001             |                 |           | 30,000     |
  | 1         | 2026-04-30          | JP_CTW_INC       | 四月服务费核销         | 2002             |                 |           | 20,000     |
  | 2         | 2026-04-30          | SH_WYYCX_INC     | 四月广告费           |                  | 销售费用            | 80,000    |            |
  | 2         | 2026-04-30          | SH_WYYCX_INC     | 四月广告费           | 1002             |                 |           | 80,000     |
