## 1.创建JE tool：

入参：

| 序号  | 字段名称                 | 字段类型    | 是否必填 | 字段说明                                                                                                                               |
| --- | -------------------- | ------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Accounting Date 会计日期 | Date 日期 | ✅ 必填 | 分录所属会计期间，格式：YYYY-MM-DD                                                                                                             |
| 2   | Company Code         | 枚举文本    | ✅ 必填 | 公司主体代码，固定枚举值：SH_WYYCX_INC / SH_CYZD_INC / JP_CTW_INC / SG_CTW_INC / US_CTW_INC / HK_CTW_INC / KY_CTW_INC / TW_CTW_INC；系统自动映射对应地区（Region），无需单独填写 |
| 3   | Description 描述       | Text 文本 | ✅ 必填 | 平账原因、业务描述、单据备注，用于对账追溯                                                                                                              |
| 4   | 分录 lines             | List 列表 | ✅ 必填 | 支持多条借贷分录（1借多贷 / 多借1贷），借贷合计须相等。每条分录包含：科目代码（Account Code）或科目名称（Report Name）**二选一**即可（两者存在强制1对1绑定，系统自动补全另一个）、借方金额（debit）、贷方金额（credit） |


> 分录约束：至少包含一条借方分录和一条贷方分录；所有分录借方金额之和 = 所有分录贷方金额之和。



**Case 1：创建 JE 分录**

用户：帮我创建一条JE

AI：好的，我来帮你创建一条 JE 分录。请提供以下信息：会计日期、公司代码（SH_WYYCX_INC / SH_CYZD_INC / JP_CTW_INC / SG_CTW_INC / US_CTW_INC / HK_CTW_INC / KY_CTW_INC / TW_CTW_INC）、描述、分录（至少一条借方、一条贷方，支持多条，借贷合计须相等；每条提供 借/贷+科目代码或科目名称 + 金额即可）。

用户：借方 1002 50000，贷方 2001 30000，贷方 2002 20000

AI：已收到凭证分录（3条，借贷已平衡）。还需补充以下 3 个必填字段才能创建：会计日期、公司代码、描述，请继续提供。

用户：会计日期 2026-04-30，公司代码 JP_CTW_INC，描述 四月服务费核销

AI：信息已收集完整，展示分录明细（JE-ID待分配 / Region JP / Company Code JP_CTW_INC / 借方1002 银行存款 ¥50,000、贷方2001 应付账款 ¥30,000、贷方2002 预提费用 ¥20,000），请财务确认。（地区由系统根据公司代码自动映射，科目名称由系统根据科目代码自动补全）

用户：（点击确认）

AI：JE 分录创建成功。展示结果表（列：JE-ID / Region / Company Code / Accounting Date / Description / Report Name / Account Code / Debit / Credit，3行：1借2贷），并附 F 系统跳转链接。



## 2.删除JE tool（只支持删除通过D创建的JE）：

入参： je_id

**Case 2-1：删除 JE**

用户：帮我删除一条JE

AI：请提供要删除的 JE 编号。

用户：JE-2026-043-0012

AI：已找到该分录，展示分录明细表，请财务确认删除。

用户：（点击确认）

AI：JE-2026-043-0012 已删除。  

**Case 2-2：删除 JE（F 系统创建，不可删除）**

用户：帮我删除一条JE

AI：请提供要删除的 JE 编号。

用户：JE-2026-031-0088

AI：已找到该分录，展示分录明细表。该分录由 F 系统自动创建（非人工录入），不支持在 D 系统中删除。

## 3.编辑JE tool（只支持编辑通过D创建的JE）：


| 序号  | 字段名称             | 字段类型    | 是否必填 | 字段说明                                                                                                                 |
| --- | ---------------- | ------- | ---- | -------------------------------------------------------------------------------------------------------------------- |
| 1   | je_id            | -       | ✅ 必填 | JE 唯一 id                                                                                                             |
| 2   | Accounting Date  | Date 日期 | 可选   | 分录所属会计期间，格式：YYYY-MM-DD                                                                                               |
| 3   | Company Code     | 枚举文本    | 可选   | 公司主体代码（同创建），修改后系统自动重新映射地区                                                                                            |
| 4   | Description 描述   | Text 文本 | 可选   | 平账原因、业务描述、单据备注，用于对账追溯                                                                                                |
| 5   | 分录 lines         | List 列表 | 可选   | 需修改的分录明细，每条包含：科目代码（Account Code）或科目名称（Report Name）**二选一**即可（系统自动补全另一个）、借方金额（debit）、贷方金额（credit）；修改后借贷合计须相等 |


> 分录约束（同创建）：如传入 lines，须至少包含一条借方分录和一条贷方分录，且借贷合计相等。

**Case 3-1：编辑 JE**

用户：帮我修改一条JE的信息

AI：请提供 JE 编号以及需要修改的字段。

用户：JE-2026-043-0012，描述改为「四月服务费结算」，借方 1002 金额改为 60000，贷方 2001 金额改为 40000

AI：已找到该分录，展示修改内容供确认：基本信息变更（描述：四月服务费核销 → 四月服务费结算）、分录变更（借方1002 银行存款：¥50,000 → ¥60,000；贷方2001 应付账款：¥30,000 → ¥40,000；贷方2002 预提费用 无变更），请财务确认。

用户：（点击确认）

AI：JE 分录修改成功。展示更新后结果表（列：JE-ID / Region / Company Code / Accounting Date / Description / Report Name / Account Code / Debit / Credit，3行：1借2贷，新金额）

**Case 3-2：编辑 JE（F 系统创建，不可编辑）**

用户：帮我修改一条JE的信息

AI：请提供 JE 编号以及需要修改的字段。

用户：JE-2026-031-0088，描述改为「ENEOS 三月结算」

AI：已找到该分录，展示分录明细表。该分录由 F 系统自动创建（非人工录入），不支持在 D 系统中编辑。
