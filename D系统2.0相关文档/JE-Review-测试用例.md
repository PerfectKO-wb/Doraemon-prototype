# F-Expert JE Review 流程测试用例

**版本**: v1.1  
**创建日期**: 2026-06-10  
**最后更新**: 2026-06-10  
**测试页面**: F-PAP-JE-REVIEW-CHAT.html  
**关联流程**: Invoice approved → AI 生成 JE（低置信度）→ 侧边栏自动创建 JE Review 会话 → 财务点击会话进入 Chat → 财务人工确认 → JE 提交 F System  

---

## 背景说明

当 AI 根据 approved invoice 生成 JE 时，若置信度低于阈值，系统自动在 F-Expert 侧边栏创建一条 **JE Review 会话**（如 JE-DRAFT-2026-0502），并附上来源 Invoice 信息。财务通过点击该会话进入 Chat 界面，与 AI 完成确认交互。财务需在 Chat 中提供以下信息：

```
Debit:
  Account: <科目名称>
  Amount: <金额>

Credit:
  Account: <科目名称>
  Amount: <金额>

Memo:
<摘要>

Tax Category:
<税区分>

Reason:
<分录理由>
```

### 七、Memo Review 流程

**流程说明**：AI 根据银行流水自动生成对账 Memo，若置信度低于阈值，系统在侧边栏创建 Memo Review 会话，财务进入 Chat 后 AI 提供流水参考信息与推荐 Memo 选项，财务选择推荐项或自行填写后确认提交。

| ID | 测试场景 | 前置条件 | 操作步骤 | 预期结果 | 测试结果 | 备注 |
|---|---|---|---|---|---|---|
| MR-01 | 低置信度 Memo 触发侧边栏创建会话 | AI 根据银行流水生成的 Memo 置信度低于阈值 | 在 F-Expert 侧边栏查看 Memo Review 会话列表 | 侧边栏自动出现新的 Memo Review 会话条目，显示来源流水摘要与金额，有待确认标识 |  |  |
| MR-02 | 点击会话进入 Chat | MR-01 完成 | 点击侧边栏中的 Memo Review 会话条目 | 右侧主区域切换为对应 Chat 界面，AI 已展示流水参考信息与推荐 Memo 选项 |  |  |
| MR-03 | 流水参考信息完整展示 | MR-02 完成 | 查看 AI 提供的参考信息区域 | 包含以下字段：Transaction Date（交易日期）、Amount（金额）、Currency（币种）、Counterparty（对方户名）、Bank Reference（银行参考号）、Description（原始流水描述）；字段对齐，格式清晰 |  |  |
| MR-04 | 推荐 Memo 选项展示 | MR-02 完成 | 查看 AI 推荐的 Memo 选项 | AI 提供至少 1 条推荐 Memo，每条附带推荐理由或置信度说明；选项以可点击的方式呈现（如按钮或编号列表） |  |  |
| MR-05 | 选择推荐 Memo | MR-04 完成 | 点击 AI 推荐的某条 Memo 选项 | Chat 中显示财务已选择该 Memo；AI 回复确认所选内容，展示最终 Memo 文本并等待提交确认 |  |  |
| MR-06 | 自行输入 Memo | MR-02 完成 | 在输入框手动输入自定义 Memo 文本并发送 | AI 识别为自定义 Memo，回复展示财务填写的内容并等待提交确认；不覆盖原推荐选项 |  |  |
| MR-07 | 先选推荐再修改 | MR-05 完成 | 在已选推荐 Memo 基础上，发送修改后的文本 | AI 以最新发送的文本为准，回复更新后的 Memo 并等待确认 |  |  |
| MR-08 | 提交确认 | MR-05 或 MR-06 完成，AI 展示最终 Memo | 点击 [确认] 按钮 | AI 回复"Memo 已提交"；[确认] 按钮消失或置灰；对应银行流水记录状态更新为已匹配 |  |  |
| MR-09 | 重复点击确认 | MR-08 完成，按钮消失前快速再次点击 | 连续点击 [确认] 两次 | 第二次点击无效，Memo 不被重复提交 |  |  |
| MR-10 | 确认后侧边栏会话状态更新 | MR-08 完成 | 查看侧边栏对应 Memo Review 会话 | 会话状态从待确认变更为已完成（或从列表移除） |  |  |
| MR-11 | 空内容提交 | MR-02 完成 | 不选择任何推荐项，也不输入内容，直接点击发送 | 发送按钮不可点击或发送后无响应，提示需要提供 Memo 内容 |  |  |
| MR-12 | 推荐 Memo 超过 3 条时的展示 | AI 对同一条流水给出 4 条以上推荐 Memo | 进入对应 Memo Review Chat | 选项展示不超出气泡边界，支持滚动或折叠查看，不影响输入框操作 |  |  |
| MR-13 | 置信度高时不触发 Review | AI 生成 Memo 置信度高于阈值 | 查看侧边栏 Memo Review 区域 | 侧边栏不创建 Memo Review 会话，Memo 直接写入流水记录无需人工介入 |  |  |
| MR-14 | 多条低置信度流水并发 | 同时存在 3 条低置信度流水 | 在侧边栏分别打开 3 条 Memo Review 会话 | 各条会话上下文独立，确认一条不影响其余条的状态与选项 |  |  |
| MR-15 | Memo 超长文本截断显示 | MR-06 完成 | 输入超过 200 字的 Memo 并发送 | Chat 气泡内长文本自动换行，不溢出；AI 回复正常接收并展示完整内容 |  |  |
